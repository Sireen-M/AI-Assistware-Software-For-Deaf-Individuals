# AI-Assistware-Software-For-Deaf-Individuals
This project presents an AI-based assistive software system that helps deaf and hard
of-hearing individuals communicate by translating sign language into audible speech. The
system employs computer vision and deep learning techniques to recognize and interpret hand
gestures that represent sign language. These gestures are then turned into real-time text.
This text is converted into natural-sounding speech with text-to-speech (TTS) technology.
The software aims to close the communication gap between sign language users and non
signers, fostering greater inclusivity in everyday interactions. The solution is lightweight,
easy to use, and scalable, making it ideal for educational and public service settings.
